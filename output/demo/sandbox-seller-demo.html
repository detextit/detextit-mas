Haggle Seller Agent

The seller now runs inside the Next.js application with OpenAI Agents SDK sandbox support. The old FastAPI sidecar path is removed, so the deployed system is one Vercel app instead of two coordinated servers.

Runtime

app/api/haggle/offer calls assistant/seller-agent.ts directly. The helper creates a SandboxAgent, stages request and history files into a Manifest, and runs the agent with a sandbox client.

Sandbox Workspace

Each run receives input/latest_request.json, state/history.json, and bin/get_pricing_guidance.py. The model uses shell/filesystem capabilities before returning the seller response JSON.

Validated Flow

A terminal buyer agent fetched /resources/skill.md, registered as demo_buyer, negotiated for Apple AirPods Pro 2, accepted the seller counter, and then verified the transaction, inventory, and leaderboard through the API.
